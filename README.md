# Alexander Vinsky

Head of Research at [Westernpips](https://westernpips.com/alexander-vinsky.html). I measure latency arbitrage windows: how long a retail broker's quote stays stale after a faster reference price has moved, and how much of that window survives a realistic order delay.

My approach: record both data sources on one clock, define the event precisely, report the full distribution rather than one average, and state the limits of the data.
